# Бот с загадками

Бот задаёт загадки разного уровня сложности, который пользователь выбирает кнопками. После ошибки бот присылает сообщение, что ответ неверный и предлагает ответить снова.

## Запуск

Нужна Java 8 или новее. Установи новый токен бота в переменную окружения `BOT_TOKEN`

Запусти бота и отправь ему `/start`. 

Если токен уже публиковался, отзови его через BotFather и создай новый. Не записывай токен в исходный код.
