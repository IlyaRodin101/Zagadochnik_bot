# ️ Telegram-бот «Загадочник» (Riddle Bot)

Телеграм-бот на Java, который предлагает пользователю загадки разной сложности. Пользователь выбирает уровень сложности с помощью интерактивных кнопок, а ответ вводит обычным текстовым сообщением. Бот проверяет наличие ключевого слова-ответа (в именительном падеже) в тексте пользователя.

## Возможности

*   **Выбор сложности**: Интерактивное меню с кнопками для выбора уровня (Легкий, Средний, Сложный).
*   **База загадок**: Набор загадок, привязанных к уровням сложности.
*   **Проверка ответов**: Бот анализирует введенный текст и ищет в нем ключевое слово-ответ (в именительном падеже).
*   **Обработка неизвестного текста**: Если пользователь вводит текст, который не является ответом на текущую загадку (или пишет что-то вне контекста), бот вежливо предложит выбрать сложность заново.
*   **Безопасность**: Токен бота не хранится в коде, а считывается из переменной окружения.

##  Технологии

*   **Язык**: Java (рекомендуется JDK 11 или выше)
*   **Библиотека**: [TelegramBots](https://github.com/rubenlagus/TelegramBots) (Rubenlagus)
*   **Сборка**: Maven

##  Запуск

Для запуска бота необходимо выполнить два основных шага: настроить переменную окружения и запустить главный класс.

### 1. Установка переменной окружения
Укажите токен бота в переменной окружения `BOT_TOKEN`.

**Для Linux/macOS (Terminal):**
```bash
export BOT_TOKEN="ваш_токен_здесь"
```

**Для Windows (Command Prompt):**
```cmd
set BOT_TOKEN=ваш_токен_здесь
```

**Для Windows (PowerShell):**
```powershell
$env:BOT_TOKEN="ваш_токен_здесь"
```

**Для IntelliJ IDEA:**
1. Откройте `Run` -> `Edit Configurations...`.
2. В поле `Environment variables` добавьте `BOT_TOKEN=ваш_токен_здесь`.

### 2. Сборка и запуск
Соберите проект с помощью Maven:
```bash
mvn clean package
```

Запустите главный класс **`Main`** (расположен в `src/main/java/ru/urfu/riddlebots/Main.java`):
*   **Через IDE**: Откройте файл `Main.java` и нажмите `Run`.
*   **Через консоль**: Запустите собранный JAR-файл:
```bash
java -jar target/riddler-bot.jar
```

## Как пользоваться ботом

1.  Найдите своего бота в Telegram и нажмите **Start** (или отправьте команду `/start`).
2.  Бот поприветствует вас и предложит выбрать сложность с помощью кнопок.
3.  Нажмите на одну из кнопок (например, «Легкая»).
4.  Бот пришлет загадку.
5.  Напишите свой ответ текстом.
    *   *Пример:* Если загадка про солнце, а вы напишете «Это солнце», бот засчитает ответ, так как в тексте есть ключевое слово «солнце» (в именительном падеже).
6.  Если вы напишете что-то непонятное (например, «привет» или «абракадабра»), бот ответит, что не понимает вас, и снова предложит выбрать сложность.
