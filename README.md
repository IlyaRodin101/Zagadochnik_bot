# Бот с загадками

Бот задаёт загадки с четырьмя вариантами ответа, которые отображаются кнопками. После первой ошибки бот даёт ещё одну попытку, после второй показывает правильный ответ и задаёт следующую загадку. После двадцатой загадки игра начинается сначала.

## Запуск

Нужна Java 8 или новее. Установи новый токен бота в переменную окружения `TELEGRAM_BOT_TOKEN`, затем из этой папки выполни:

```text
javac -encoding UTF-8 -source 1.8 -target 1.8 Main.java TelegramBot.java Riddle.java Game.java JsonParser.java
java Main
```

В PowerShell переменную можно задать для текущего окна так:

```powershell
$env:TELEGRAM_BOT_TOKEN = "новый_токен_от_BotFather"
```

Запусти бота и отправь ему `/start`. Команда `/help` показывает правила, а `/start` начинает игру заново.

Если токен уже публиковался, отзови его через BotFather и создай новый. Не записывай токен в исходный код.
